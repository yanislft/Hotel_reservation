# Hotel Reservation Site

Hotel Reservation Site est une application web moderne conçue pour simplifier la gestion des réservations hôtelières. Elle offre une interface intuitive et des fonctionnalités robustes permettant aux utilisateurs de découvrir les services, consulter les chambres disponibles et effectuer des réservations en ligne.

## Fonctionnalités principales

### Réservation en ligne
Interface conviviale permettant aux utilisateurs de réserver facilement des chambres ou des suites.

### Gestion des réservations
Possibilité d’ajouter, de modifier ou de supprimer des réservations via un panneau d’administration.

### Présentation détaillée
Chaque type de logement dispose d'une page dédiée présentant ses caractéristiques, son prix et ses disponibilités.

### Multimédia enrichissant
Intégration d’images et de vidéos pour une meilleure immersion et compréhension des services proposés.

### Interface responsive
Design adaptatif garantissant une expérience utilisateur optimale sur ordinateurs, tablettes et smartphones.
